# 产品背景（Product Context）

## 为什么做

现有播放器要么是"歌单驱动"（需要管理），要么界面过于现代。本项目想还原**老式收音机**的使用体验：

- 没有明确的"下一首"，只有频道旋钮和随机
- 有底噪、有数码管、有实体按键的触感
- 打开就能听，不需要决定听什么

## 用户场景

1. **桌面/移动端日常听歌**：导入文件夹，按 CH1 随机播放
2. **专注工作背景音**：打开底噪推子，叠加海浪 + 粉红噪声
3. **收藏偏好曲目**：红心后切到 CH2 只听收藏
4. **听在线电台**：把常听的电台流绑定到 `3`–`9` / `*` / `0`，按一下即播；电台较多时绑定 `10`–`9999` 编号，用 `#` 输入编号收听（最多 1000 条）
5. **直达某一首 / 某个台**：知道曲目序号时，按 `#` → 输入序号 → `#`，立即跳到第 N 首（`1`/`2` 保留给随机 / 红心）；若该编号绑定了串流则优先播流
6. **整点时间感**：播放中每到整点自动响钟声并用系统语音报时，适合长时间当作背景电台

## 体验原则

- **极简**：主界面只保留数据卡片、控制栏、九宫格、双推子
- **即时反馈**：所有开关/主题/推子实时生效；LED 状态条承担提示职责
- **复古但不难用**：深色/浅色主题都要保证可读性（含设置弹层）
- **可离线**：核心资源由 Service Worker 预缓存，海浪音频按需缓存

## 视觉与主题

5 种整页主题，切换时页面背景、文字、分隔线、卡片辉光、状态栏配色同步联动：

| 值 | 名称 | 基调 |
| --- | --- | --- |
| `dark` | 默认 · 黑底橙字 | 米白页 + 黑卡片 |
| `led` | LED · 灰底黑字 | 米白页 + LED 灰卡片 |
| `crt` | 冷光绿 · 示波器 | 深黑底 + phosphor 绿辉光 |
| `cream` | 暖白奶油 · 卡带机 | 深暖棕底 + 奶白柔光 |
| `tube` | 暗红琥珀 · 真空管 | 深红棕底 + 琥珀暖辉光 |

另有 8 种强调色（主题色圆点）可独立微调。
