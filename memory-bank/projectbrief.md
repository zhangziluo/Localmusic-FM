# 项目简介（Project Brief）

**极简FM** —— 一个零依赖、纯前端的本地音乐电台 PWA，模拟一台"极简 FM 收音机"。

## 核心目标

- 导入本地音乐文件夹 → 随机播放，不使用播放列表，追求 iPod shuffle 的"盲盒感"
- 用 Web Audio 合成收音机底噪（粉红噪声 + 海浪），叠加在音乐之上
- 复古仪表风界面：LED 状态条、DSEG14 数码管数据卡片、实体感九宫格键盘、双竖推子
- 可安装为 PWA，首次加载后可离线使用
- 在本地曲库之外，支持把在线电台 / 网络串流绑定到实体按键上收听
- 支持按曲目序号直接跳转（`#` → 数字 → `#`），同时保留 `1` 随机 / `2` 红心的核心行为
- 播放中整点自动报时（12 小时制钟声 + 系统 TTS），地点按设备时区推断

## 范围（当前）

- 单页应用：`index.html` + `style.css` + `app.js` + `sw.js` + `manifest.json`
- 无构建步骤、无第三方运行时依赖、无测试框架
- 目标浏览器：移动端 Safari / Android Chrome 优先，桌面 Chromium 完整支持

## 非目标

- 不做歌单 / 播放队列管理
- 不做账号、云同步、服务端
- 不做音乐库元数据（封面、歌手、歌词）解析

## 成功标准

- 打开即用（静态服务器即可运行），可安装、可离线
- 按键 / 推子 / 主题切换全部即时响应
- 新增主题与网络串流不破坏原有曲库播放与收藏逻辑
- 网络串流的绑定不破坏原有曲库播放与收藏逻辑：直接按 `1` 仍是随机、`2` 仍是红心
